🔥 RAAZ Privacy Policy

Last updated: September 2026

RAAZ ek chat application hai jahan users apne doston se private messages kar sakte hain. Ye policy batati hai ki hum kaunsa data collect karte hain aur usko kaise use karte hain.

1. Hum kya data collect karte hain

  • Naam, username, aur email address (jab tum sign up karte ho)
  • Profile photo aur bio (agar tum add karte ho — optional hai)
  • Jo messages tum bhejte/receive karte ho
  • Basic activity info (jaise last active time, taaki online/offline status dikha sakein)

2. Data kaha store hota hai

Sara data Google ke Firebase (Cloud Firestore) servers par store hota hai — ye industry-standard aur secure infrastructure hai jo Google khud bhi apne products ke liye use karta hai.

3. Hum data ka use kaise karte hain

  • Sirf app ko chalane ke liye — login, chat, profile dikhana
  • Hum tumhara data kisi ko bechte nahi hain
  • Hum tumhare messages ko padhte ya monitor nahi karte
  • Koi third-party advertising nahi hai is app me

4. Kaun tumhara data dekh sakta hai

  • Tumhari private chats sirf tum aur jisse chat kar rahe ho, wahi dekh sakte hain
  • Tumhara naam, username, photo, aur bio — ye basic profile info koi bhi dusra logged-in user dekh sakta hai (jaise Instagram par public profile hoti hai), taaki wo tumhe search karke connect kar sake
  • Message requests ka system hai — koi bhi tumhe direct message nahi kar sakta jab tak tum unki request accept nahi karte

5. Apna data delete karwana

Agar tum apna account aur data poori tarah delete karwana chahte ho, app ke owner se contact karo. Hum tumhara data reasonable time ke andar delete kar denge.

6. Security

Hum Firebase Security Rules use karte hain taaki koi bhi bina login ke tumhara data access na kar sake, aur koi doosra user tumhara private data (jaise chats, blocked list) na dekh sake.

7. Bacchon ke liye

Ye app kisi bhi age-verification system ke saath nahi aata. Agar tum minor ho, kripya apne parents/guardian ki permission se hi use karo.

8. Contact

Kisi bhi sawal ya concern ke liye, app ke owner se seedha contact karo.

⚠️ Disclaimer: Ye ek basic, personal-project-level privacy policy hai jo chhote scale (doston/community) ke liye banayi gayi hai. Agar ye app aage jaake bade level par publicly launch hoti hai ya isse paisa kamaya jata hai, to ek professional lawyer se poori legal-compliant policy banwana recommended hai.
