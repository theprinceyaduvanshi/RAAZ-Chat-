🔐 RAAZ Privacy Policy

Last updated: September 2026

📋 Introduction

RAAZ ek private messaging app hai jahan aap apne doston aur family ke saath secure chats kar sakte hain. Hamari top priority aapki privacy hai. Yeh policy batati hai ki hum kaunsa data collect karte hain aur kaise use karte hain.

1️⃣ Hum Kya Data Collect Karte Hain

  • Basic Info: Naam, username, email address (signup ke waqt)
  • Profile Data: Profile photo, bio (optional - aap khud add karte hain)
  • Messages: Jo messages aap bhejte/receive karte hain (text, photo, voice)
  • Status: Aapke status posts (24-hour stories)
  • Call Data: Voice call information (duration, time)
  • Activity: Last active time (online/offline status ke liye)

2️⃣ Data Kahan Store Hota Hai

Sara data Google Firebase (Cloud Firestore) servers par store hota hai - yeh industry-standard, enterprise-grade secure infrastructure hai jo Google khud apne products ke liye use karta hai.

3️⃣ Data Ka Use Kaise Hota Hai

  • Sirf app chalane ke liye - login, chat, profile, status, calls
  • Hum aapka data kisi ko bechte nahi
  • Hum aapke messages padhte ya monitor nahi karte
  • No third-party advertising

4️⃣ Kaun Aapka Data Dekh Sakta Hai

  • Private Chats: Sirf aap aur jisse chat kar rahe hain
  • Public Profile: Naam, username, photo, bio - koi bhi logged-in user dekh sakta hai
  • Status: Sirf aapke contacts/friends dekh sakte hain
  • Message Requests: Direct messages nahi milte jab tak aap request accept na karo
💡 Note: Aap apna data kabhi bhi delete karwa sakte hain. Contact karein aur hum reasonable time mein delete kar denge.

5️⃣ Security

Hum Firebase Security Rules use karte hain taaki:

  • Koi bhi bina login ke data access na kar sake
  • Dusre users aapka private data na dekh sakein
  • Blocked users aapko message na kar sakein

6️⃣ Contact

Kisi bhi sawal ya concern ke liye app ke owner se contact karein.

⚠️ Disclaimer: Yeh ek basic personal-project privacy policy hai. Agar yeh app publicly launch hoti hai, professional legal advice lena recommended hai.
